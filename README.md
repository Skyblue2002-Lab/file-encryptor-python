# File Encryptor - Python Cryptography Tool 🔐

## Description
A Python-based cryptography tool that allows users to encrypt and 
decrypt files and messages to protect sensitive data. Built as part 
of a cybersecurity project at the Federal University of Lafia.

## Features
- Encrypt text messages and files
- Decrypt encrypted files and messages
- Supports Word documents and PDF files
- Lightweight and runs offline

## How to Run
1. Install Python 3.x
2. Install dependencies:
   pip install cryptography
3. Run the project:
   python project.py

## Technologies Used
- Python
- Cryptography library
